# Lab 1 - Introduction to NLP

This lab uses the **SMS Spam Collection** to explore labelled text messages.

## Completed tasks

1. Select an online text dataset and identify its source, format, and purpose.
2. Download and open the dataset with pandas.
3. Follow the instructor's examples: preview rows, display descriptive statistics and column information, and count the classes.

Open [Lab 1.ipynb](Lab%201.ipynb) for the completed work and saved outputs. The notebook also checks missing values and duplicate rows as a small data-quality check. No model training is required for this lab.

## Files

- `Lab 1.ipynb`: completed notebook with explanations and results.
- `data/SMSSpamCollection.txt`: original tab-separated data, with a `.txt` extension added.
- `data/README.md`: source, format, attribution, and download details.
- `data/SOURCE_README.txt`: the dataset authors' original documentation.

The included file contains 5,574 messages: 4,827 ham and 747 spam. All rows are retained for this introductory exploration.

For installation and launch instructions, see the [repository README](../README.md).
